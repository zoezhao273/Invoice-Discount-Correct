Invoice Discount Corrector

The billing system rounds discounts from 2 decimals to 1, which introduces errors. This tool corrects the discount under the 2-decimal unit-price limit — keeping each invoice's tax and total intact wherever possible — then splits the file into a ready-to-upload set and a manual-invoicing set.

Everything runs in your browser — no data is uploaded to any server

How it works
  1. Verify — checks each row's Subtotal, IVA and Total, and flags any arithmetic mismatch already present in the file.
  2. Correct — rounds the discount to 1 decimal and nudges the unit price (quantity and unit price are treated as correct) so each invoice's tax base, tax and total stay intact.
  3. Split — invoices that reach zero error go to Ready to upload; invoices with no solution at 2 decimals are exported unchanged under Invoice manually, for you to issue by hand.
